## 0. 核实方法（三层证据 + 哈希比对）

| 层级 | 内容 | 作用 |
|---|---|---|
| 证据 A：本地文件声明 | 字体 name 表、CSS/JS 文件头部许可证注释 | 证明"仓库内自述" |
| 证据 B：上游官方原文 | 官方仓库 README/LICENSE（jsDelivr 拉取 @版本标签）、官方许可页面 | 证明"上游确实如此授权" |
| 证据 C：哈希比对 | 本地文件 SHA-256 == 官方发行文件 SHA-256 | **证明"本地文件就是官方那份"**（版本一致性最硬证据） |

> 三层齐全 = 满足 v2.1 模型"已核实"的证据要求（名称+版本+来源+原文+适用范围+条件核对）；
> 最终状态转"已核实"需登记白名单（`config/whitelist.yaml`，待技术部负责人确认生效）。

## 一、字体系列核实明细（3 个）

### 1. Font Awesome 4.7.0 ✅ 核实通过

| 项 | 结果 |
|---|---|
| 文件 | `fontawesome-webfont.{ttf,woff,woff2,eot}` + `FontAwesome.otf`，2 模块共 10 处位置 |
| 证据 A（本地） | CSS 头部：`Font Awesome 4.7.0 ... License - http://fontawesome.io/license (Font: SIL OFL 1.1, CSS: MIT License)`；字体 name 表 `Version 4.7.0 2016`、`license_url=http://fontawesome.io/license/` |
| 证据 B（官方原文） | 官方仓库 `FortAwesome/Font-Awesome@4.7.0` README License 段：**字体 = SIL OFL 1.1；CSS/LESS/Sass = MIT；文档 = CC BY 3.0** |
| 证据 C（哈希） | 本地 ttf `SHA256 AA58F33F…C0D6A8` **== 官方 4.7.0 发行 ttf** ✅ |
| 许可证结论 | 字体 **OFL-1.1**（允许商用、嵌入、分发；需保留版权与许可声明）；CSS 代码 MIT |
| 条件核对 | OFL 无嵌入限制，与 fsType=0 一致；报告/页脚保留 Font Awesome 署名 |
| 残留技术项 | CSS 中出现 `Font Awesome 5 Free`（AdminLTE dist 遗留引用）→ 与本字体无关，建议前端确认是否仍被引用（非合规问题） |

### 2. Ionicons v2.0.0 ✅ 核实通过

| 项 | 结果 |
|---|---|
| 文件 | `ionicons.{ttf,woff,eot}`，2 模块共 6 处位置 |
| 证据 A（本地） | `ionicons.min.css` 头部完整声明：`Ionicons, v2.0.0 ... MIT License: https://github.com/driftyco/ionicons`，并注明图标衍生自 Google Material Icons（**CC BY 4.0**） |
| 证据 B（官方原文） | 上游 `driftyco/ionicons` LICENSE = MIT（jsDelivr 获取） |
| 证据 C（哈希） | 本地 ttf `SHA256 2BA7F20B…36F5F9` **== 官方 ionicons@v2.0.1 ttf** ✅（字体文件 2.0.0→2.0.1 未变更） |
| 许可证结论 | 字体 **MIT**；图标含 Google Material 衍生成分 **CC BY 4.0（需署名）** |
| 条件核对 | 保留 MIT 声明；界面/文档保留 Material Icons 署名 |
| 备注 | 字体 name 表无许可证字段（扫描器判"未知"的根因）——**证据在 CSS 头部**，实证了"双引擎+文件关联"的必要性 |

### 3. GLYPHICONS Halflings ✅ 有条件通过（建议登记 + 署名）

| 项 | 结果 |
|---|---|
| 文件 | `glyphicons-halflings-regular.{ttf,woff,woff2,eot}`，2 模块共 8 处位置；字体版本 `1.009`，版权 `Copyright © 2014 by Jan Kovarik` |
| 证据 C（哈希） | 本地 ttf `SHA256 E3950440…F57456` **== 官方 Bootstrap v3.4.1 发行 ttf** ✅ |
| 证据 B（官方声明） | Glyphicons 官方（glyphicons.com，经 Bootstrap issue #4485/#3942 引用）："Glyphicons Halflings … released under the same license as Bootstrap"；Bootstrap v3 = MIT；Bootstrap 官方文档长期建议署名（Twitter/Bootstrap 页脚做法：`Icons from Glyphicons, licensed under CC BY 3.0`） |
| 许可证结论 | **随 Bootstrap 官方发行并获作者授权免费使用**（非商业字体）；建议按惯例保留 glyphicons.com 署名链接 |
| 风险点（如实记录） | ① 包内无 LICENSE 文件；② 许可文本历史表述有 Apache 2.0（Bootstrap v2 时代）/ MIT（v3 时代）差异；③ "Glyphicons Free(CC BY 3.0)"与"Halflings 特殊安排"是两套说法，官方 issue 中长期存在争议 |
| 处置建议 | **保留使用 + 页脚署名**（成本最低、与官方生态一致）；若要求证据绝对闭合，可升级 Bootstrap 5 或换 bootstrap-icons（MIT/OFL，fsType=0） |
| fsType=4 说明 | 嵌入限制位存在，但官方授权安排明确允许随 Bootstrap 在网页中使用（数百万站点实践）；按 v2.1 规则维持"待评估"记录，以本报告为授权依据 |
